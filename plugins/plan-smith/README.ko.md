## 진입점

```
/plan-smith:plan-smith [frame=<프레임>] [style=opus|fable|relay|auto] <태스크 설명>
```

자연어 요청("… 플랜 짜줘")으로도 스킬이 트리거됩니다. 산출물: `plans/<slug>/{packet.md, plan.md[, draft.md, audit.md]}`.

## 설계 불변식

1. 메인 에이전트는 **플랜을 직접 쓰지 않는다** — 의도만 증류한다. 추출은 컨텍스트 잡음을 견디지만 집필은 못 견딘다.
2. **확인된 패킷 없이 집필 없음** — 추측 필드는 전부 `⚠guess` 표시 후 사용자와 해소한다. 판단이 애매하면 즉시 묻는다.
3. 집필자의 입력은 **자기완결** (패킷 + 인라인 프레임/스타일 스펙) — 세션 접근 없음, 경로 추측 없음.
4. **원문 릴레이** — 플랜 파일은 전문 제시. 요약은 규약 위반.
5. 스타일은 **모델 선택이 아니라 프롬프트 규율** — 26개 플랜 통제 실험에서 증류되고 100플랜 검증 코퍼스로 스트레스 테스트되었다. relay 직렬 연결과 모델 간 이식성은 아직 '유망하나 미검증'이며, 회고 데이터가 그 증거를 축적한다.
